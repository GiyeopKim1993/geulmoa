# 글모아 — 화면에서 쓰는 손글씨 폰트 실험실

펜·터치·마우스로 대표 음절을 쓰고, 초·중·종성을 상황별로 조합해 TTF를 만드는 **실험용 웹 프로토타입**입니다. 서버에 필기를 올리지 않고 브라우저에서 폰트를 생성합니다.

## 실행

미리 컴파일된 `site/worker.js`가 포함되어 있어 Node.js가 있으면 바로 실행할 수 있습니다.

```bash
npm start
# 브라우저에서 http://localhost:4173
```

소스를 변경하고 워커를 다시 만들거나 테스트하려면:

```bash
npm ci
npm run build
npm test
npm start
```

브라우저 입력·색칠·폰트 다운로드까지 자동 점검하려면 Chromium을 설치하고, 별도 터미널에서 `npm start`를 실행한 뒤 다음을 실행하세요.

```bash
npx playwright install chromium
npm run test:browser
```

`site/`는 정적 사이트로도 호스팅할 수 있습니다. 파일을 `file://`로 열면 웹 워커 정책 때문에 동작하지 않을 수 있으므로 HTTP로 서빙하세요.

## GitHub Pages 배포

이 저장소를 GitHub에 올린 뒤 **Settings → Pages → Build and deployment → Source**에서 **GitHub Actions**를 선택하세요. `main` 브랜치에 푸시하면 `.github/workflows/deploy-pages.yml`이 `site/` 폴더를 배포합니다. 이미 푸시한 경우 **Actions → Deploy GitHub Pages → Run workflow**로 실행할 수 있습니다. 공개 저장소의 사이트는 `https://사용자명.github.io/저장소명/`에서 열립니다. 앱은 경로 접두사가 있는 주소에서도 동작하도록 상대 경로를 사용합니다.

## 사용 방법

1. **기초 음절 16자**를 한 음절씩 선택하고, 초성·중성·종성을 나누지 않은 채 글자 전체를 화면에 씁니다. 펜·손가락·마우스를 사용할 수 있습니다.
2. **자모 색칠**로 넘어가 초성(보라)·중성(청록)·종성(주황)을 선택하고, 방금 쓴 해당 획 위를 문질러 색칠합니다. 남은 검은 획과 필요한 자모는 진행 표시에서 확인합니다. 받침이 없는 글자에는 종성이 나타나지 않습니다.
3. 붓 크기를 조절하고, 잘못된 부분은 다른 색으로 다시 칠하거나 **색 지우개**로 미분류 상태로 돌릴 수 있습니다. 되돌리기와 **색칠만 초기화**도 가능합니다. 숫자·기호는 색칠 없이 쓸 수 있습니다.
4. 선택 사항인 **ㄱ 문맥 9자**, 숫자·기호를 추가하거나 원하는 한글 음절을 직접 추가합니다. `내 폰트 만들기`를 누르고 문장을 확인한 뒤 `.ttf`를 다운로드합니다. 자모 색칠이 끝나지 않은 글자는 이번 생성에서 제외하고, 부족한 자모는 결과에서 안내합니다.

화면에서 필기를 하면 이 기기의 브라우저 `localStorage`에 저장됩니다. 공용 기기에서는 사용 후 초기화하세요. 브라우저 저장 데이터를 지우거나 시크릿 모드를 닫으면 작업이 사라질 수 있습니다. 폰트는 파일로 내려받아 별도 보관해야 합니다.

## 처리 방식과 한계

- 글자를 먼저 한 번에 쓰고 사용자가 실제 획을 초성·중성·종성 색으로 칠해 픽셀 단위로 분리합니다. **글자나 자모를 자동 판독하는 AI 모델은 아닙니다.** 검은 미분류 획이 남거나 필수 자모 색이 빠진 음절은 폰트 생성에서 제외합니다. 숫자·기호는 제외 대상이 아닙니다.
- 색칠은 기존 획에만 적용되며 TTF에는 색이 들어가지 않습니다. 닿거나 교차하는 획은 작은 붓으로 직접 나눌 수 있지만, 같은 픽셀은 한 자모에만 속합니다. 자모의 올바른 모양까지 자동 검증하지는 않으므로 색칠을 직접 확인해야 합니다.
- 기존 방식으로 저장한 필기와 자모 지정은 보존됩니다. 잘못 지정한 부분은 덧칠하거나 `색칠만 초기화`한 뒤 다시 나눌 수 있습니다.
- 완료된 음절은 원본 획의 외곽선을 우선 사용합니다. 다른 음절은 수집한 동일 자모 중에서 모음의 가로·세로·복합 및 획 방향, 받침 유무·종류, 주변 초성의 유사성 등을 휴리스틱으로 비교하여 선택합니다. 부족한 겹자음·복합 모음 등은 다른 자모를 변형해 추정합니다.
- 16개 기초 음절이 제대로 입력되고 필요한 자모가 추출되면 이론적으로 현대 한글 완성 음절 11,172개를 만들 수 있습니다. **코드포인트 범위가 완전하다는 뜻이지 모든 글자가 읽기 쉽거나 필체를 정확히 복원한다는 뜻은 아닙니다.** 특히 복합 모음·겹받침·두꺼운 획은 사용자 검수가 필요합니다.
- 원본 획 좌표를 저장하지만 현재 필압과 속도는 반영하지 않고 고정 폭을 사용합니다. 영문, 옛한글, 한자, 이모지 및 분해형 자모 OpenType 셰이핑은 미지원입니다. 공백과 입력한 숫자·기호, 가능한 한글 호환 자모는 포함됩니다.
- 앱은 결과에 지원하지 않는 문자를 안내합니다. ‘한 글자 살펴보기’에서 직접 쓴 음절인지, 조합한 음절인지와 각 자모의 출처를 볼 수 있습니다. 생성 직후 글씨를 수정하면 기존 다운로드가 오래된 버전이므로 다시 생성해야 합니다.
- 생성은 웹 워커에서 실행됩니다. 큰 폰트는 기기 성능에 따라 시간이 걸리고 메모리를 사용합니다.

## 코드 출처와 라이선스

한글 조합, 자모 유도, 윤곽과 TTF 생성의 기반은 [kor-your-font](https://github.com/maxi08aidot/kor-your-font) 및 원작 [draw-your-font](https://github.com/danilo-znamerovszkij/draw-your-font)의 MIT 코드입니다. 원본 저작권 및 MIT 라이선스는 `LICENSE`에 보존했습니다. 화면 필기 후 수동 색칠 분리와 문맥별 샘플 선택, UI는 이 프로토타입에서 추가했습니다.

브라우저 윤곽 추적에는 `imagetracerjs` (Unlicense), 경로 처리에는 `svgpath` (MIT), TTF 생성에는 `svg2ttf` (MIT)를 사용합니다. `vendor/svg2ttf`에는 한글 이름과 ASCII PostScript 이름 분리, 잘못 인코딩된 Mac 이름 방지, post 테이블 길이 수정을 위한 작은 변경이 포함됩니다. 라이선스 고지문은 `site/third-party-licenses.txt`에 있습니다. 상용 배포 전에는 의존성의 전체 라이선스, 폰트 생성물과 입력 데이터의 사용 권리를 별도로 확인하세요.
