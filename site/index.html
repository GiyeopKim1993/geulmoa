글씨 경로의 크기는 맞추고, 획의 굵기는 따로 정해 다시 그려 봅니다.

새 로컬 실험
외곽선을 깎지 않습니다. 저장된 획 경로를 조정한 굵기로 다시 그린 뒤 비교용 윤곽을 만들어요. 이 비교는 직접 쓴 한글 최대 30자와 지정한 조합 글자만 담는 별도 실험입니다. 위의 실제 폰트 자동 보정은 별도 안전검사를 거치므로 결과가 다를 수 있어요. 숫자·기호는 비교에서 제외해요.
1. 비교할 글씨

같은 펜으로 작게·크게 쓴 가상의 예시예요. 실제 손글씨가 아닙니다.

0%는 기존 결과 · 100%는 사용 가능한 획을 기준 굵기로 다시 그려요.

직접 쓴 글자들의 기본 굵기를 기준으로 더 얇거나 두껍게 조절해요.

다른 주소에 저장한 글씨로 비교하기 선택

주소가 다르면 저장된 글씨가 자동으로 연결되지 않아요. 컴퓨터에서 다른 주소의 글모아를 열고 개발자 도구(F12)의 Application → Local Storage → 사이트 주소에서 geulmoa-drawing-v1 항목의 Value를 복사해 아래에 붙여 넣어 주세요. 서버로 전송하거나 다른 주소의 원본을 수정하지 않습니다.

글자별 비교

조합 글자는 사용자가 칠한 픽셀을 따라 저장된 경로를 나눕니다. 경계가 충분히 재현되지 않거나 직접 쓰지 않아 추정한 자모는 기존 윤곽을 유지해요. 다시 그린 곡선과 획 끝이 기존 윤곽과 조금 달라질 수 있고, 굵기에 따라 획이 붙거나 ㅇ의 구멍이 작아질 수도 있어요. 입력은 현재 고정 굵기라 필압은 반영되지 않습니다.
